## 📖 About This Challenge

> **i am starting working on 30 days python programing challenge**

This repository is my daily log of learning Python by *actually writing code* — no shortcuts, no skipped days (well, almost 😅). Every folder is one day of practice: small programs that build on each other, starting from plain syntax and working up to recursion and real file-handling projects with live datasets.

If you're learning Python too, feel free to fork it, clone it, or steal an idea or two. 🐍
